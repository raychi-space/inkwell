# Raychi v0.2 · inkwell 管理台任务说明

本文保留早期任务范围；对应[模块 Issue #2](https://github.com/raychi-space/inkwell/issues/2)及已完成的[跨仓主 Issue #1](https://github.com/raychi-space/raychi/issues/1)。项目级产品依据见 [Raychi 产品需求 v0.2](https://github.com/raychi-space/raychi/blob/main/docs/product-v0.2.md)。后续内容已收敛为文章和帖子，写作与发布流程也已迭代；当前站长操作以 [README](../README.md)与[写作助手说明](writing-assistant-v1.md)为准，下文不是当前功能进度或使用说明。

## 站长路径

1. 在内容管理中分别创建长文、帖子和思考。三类内容均可暂存草稿、打开继续编辑、发布、修改已发布工作稿、再次发布和撤回。发布后立即公开；仅保存工作稿不更新访客看到的版本。
2. 长文标题必填，正文支持现有 Markdown 写作与图片粘贴，封面可选。帖子、思考标题可空，正文使用 Markdown 文字能力但不提供图片上传或插入操作。帖子重点支持换行和链接；思考支持段落、列表、引用、行内代码和链接。
3. 分类与标签由站长自行添加和选择。长文选一个分类和多个可选标签；帖子只显示标签；思考只显示分类。长文与思考共用分类，长文与帖子共用标签；未选分类时明确提示使用默认分类。
4. 网站设置可修改站名、简短介绍、头像、联系方式、外部账户、导航文字和链接，以及首页预设区块的显示与顺序。点击保存后立即生效；设置界面不提供草稿/发布步骤，也不触碰内容工作稿。

## 接口依赖与交付

- 等待 wellspring 确认三类内容、分类/标签管理和站点配置的管理 API、校验与错误结构。保留当前会话和 CSRF 边界，不直接写数据库。
- 编辑器继续以 Markdown 为正文数据，维护加载、编辑、暂存、重开和公开显示的语义一致性。帖子/思考不应保存图片 Markdown；不支持的格式不可静默丢失。
- 长文现有图片私密预览、未完成上传阻止发布及发布快照行为需要继续工作。无标题内容的 URL 不由界面临时拼接或强制要求作者填写。

## 模块验收

- 三种内容从创建到暂存、重开、发布、修改、再次发布、撤回均可操作；已发布内容仅暂存后访客仍读旧版。
- 帖子/思考无标题可发布；三类表单只展示适用字段；分类和标签新增后能选择并在重开时保留。
- 站点设置保存即生效，未触发内容发布；失败时保留未保存输入并给出可理解的错误。
- 运行 `npm run build`，并与当前后端做真实浏览器验证，覆盖 Markdown 往返、权限、图片与配置保存。
