文档核对：2026-10-08。保存与发布使用当前[发布预览流程](../README.md#保存与发布预览2026-10-03)；旧停顿摘要和发布后自动摘要仅保留兼容接口，不能作为当前界面的使用步骤。

## 使用

侧栏“助手管理”是独立的助手列表与详情页面。模型服务商在“网站管理”的最下方，支持新增配置，使用独立的“保存服务商”按钮。先在这里新增 OpenAI-compatible 服务商（API 地址为 `/chat/completions` 前缀），逐项填写并添加实际模型 ID、密钥后保存，再测试聊天连接与工具能力。模型 ID 不能重复或为空；输入新的 ID 后须先添加到列表再保存。修改配置时先保存，连接测试使用已保存的地址、密钥与模型。

重新打开服务商时默认保留已保存密钥，页面不读取明文；设置/替换与清除是明确动作。在助手管理新增助手时填写名称、选择服务商与模型、配置提示词和固定背景，“运行设置”可展开调整上下文、超时与输出预算。配置通过已有接口保存在内核服务。切换同一区域的未保存配置时可返回编辑或放弃修改，操作说明见[管理台页面与侧栏](management-ui.md)。

写作页左侧是文章 MDXEditor，分类和标签移到发布预览弹窗；顶部不再常驻发布信息区域。编辑区与工具栏保持固定高度，正文在内部滚动。右侧为可收起的对话框，历史独立滚动，输入区固定在底部；输入支持回车发送、Shift+Enter 换行、展开多行与中文输入法。展开和收起使用布局与淡入淡出动画，系统偏好减少动态效果时关闭动画。收起后对话、输入和选区保留，隐藏面板不可聚焦。普通发送是正常对话；每轮任务使用最新未保存正文，带最近完整对话和建议的确认状态。页面刷新、切换文章后对话重新开始；晚到任务无法应用到新页面。一次只允许一个在途任务或待确认建议，对话使用 SSE 接收累计文本；元数据任务仍查询完整状态。服务失败时现有编辑内容保留。

## 选区支持与确认

在正文用鼠标或键盘选择文字，右侧自动显示“已选中选区”，不需要点击引用按钮，也不会因此调用模型。更换选区会更新引用；移到消息框后引用保留，可点击“移除引用”清除。任务执行或建议待确认期间，选区不会被新选择替换。询问或讨论保留引用并正常回答；明确提出修改要求时，模型可以提供待确认的改写建议。没有引用时可以正常对话或提出全文修改建议；整篇建议返回完整 Markdown 与本轮快照标识，用户确认后才应用。意图判断依赖模型遵守指令；强制边界是只允许本轮选区或正文快照 ID、校验结果和用户确认，不会直接修改正文。选区变化在编辑器更新后读取，通过 MDXEditor 的公开 realmPlugin/rootEditor$ 注册 Lexical 根编辑器，并在同一同步读取中保存 RangeSelection 克隆、原文文本与公开 getSelectionMarkdown 的 Markdown。

第一期支持**根编辑器的无格式文字段落，以及这些段落中的连续选区**。两个端点必须是 TextNode。选中的段落不能带粗体、斜体、链接、内联代码或换行节点；标题、列表、引用、表格、图片、代码块和嵌套编辑器暂不支持，界面明确提示。没有富文本到 Markdown 偏移换算，也不查找首个匹配字符串。接受时按节点 key/offset 书签检查有效性与原文，恢复选区，通过公开 insertMarkdown$ 导入新 Markdown，在同一次带 HISTORY_PUSH_TAG 的 Lexical 更新中替换。新内容支持已安装插件的 Markdown 导入；空字符串明确显示“删除选区”。相同 Markdown 显示“没有修改”。

普通对话执行时正文可继续编辑，发送期间保存/发布禁用。返回改写建议后正文只读、工具栏不可操作、保存/发布禁用。红色原文与绿色新文用独立 React portal 展示在段落附近，越靠近底部会限制预览高度，差异部分可以滚动、操作按钮固定可见。预览不插入 Lexical，不参与 Markdown 或草稿保存。

接受选区建议只消耗一次书签，形成独立撤销记录，正常 onChange 标记工作稿。接受全文建议再次比较当前 Markdown 与原快照，以一次 Lexical 历史更新替换正文并明确标记未保存；可一次撤销和重做，保存仍由用户触发。拒绝只是释放书签，从未修改正文。书签失效、原文变化或编辑器重挂载时报“原文已变化，请重新选择”，不自动合并。保存与发布仍需站主明确操作；生成或接受不会发布。

## 发布元数据、历史与故障

帖子无需标题、摘要或助手即可保存和发布，地址为稳定随机 UUID。以下生成步骤只适用于文章。

单纯输入和停顿不会生成摘要。保存先持久化工作稿，再通过选中的助手生成并保存发布标题、摘要与英文地址别名，不弹窗、不公开；点击发布先完成相同准备流程，再在预览中编辑确认。生成期间锁定编辑与提交，模型失败保留已保存正文并可重试；没有已启用助手时提示先配置。关闭浏览器可能中断元数据回写，但正文已经保存。

确认发布才更新公开快照；取消预览不公开。已发布内容地址只读，发布标题与正文标题独立；确认的摘要不再被后台任务覆盖。相同已准备工作稿可复用结果，具体版本与地址唯一性以内容服务契约为准。旧客户端的发布后摘要任务仍绑定发布快照，重新发布、撤回或删除后不会应用过期结果。

下一轮重新捕获最新上下文，助手记录附已接受/拒绝/过期状态，历史工具调用不会重新执行。历史存本页状态，Provider/Assistant/任务在服务端持久。选择新助手不会恢复旧会话。

回复气泡显示当前账户名、网站头像和助手图标，累计 SSE 文本替换同一气泡；只有最终结构化 proposal 能应用正文。断线、退出或改密后连接结束，底层任务继续受超时限制。

网络失败可“重试本次提交”，复用整个原请求与 requestId，避免重复模型任务。对话任务失败后重新发送会用新 ID。过期选区不能用网络重试重新应用。超时、非法结果、上下文超限等展示后端可读原因并保持正文。

## 验证与启动

`npm ci --ignore-scripts && npm run build`。开发模式 `?editor-agent-fixture=1` 提供无后端/模型的固定替换验证页（生产不可进入），检查重复文字、捕获后焦点切换、接受、拒绝、Markdown 导出与撤销。后端配置独立 Agent 服务后用真实管理台任务接口联调；本期模拟模型验收和截图见 raychi 主 Issue，真实模型由用户随后配置。

实现使用 MDXEditor4.3.0 与 Lexical0.48.0 的公开 API；依赖 Lexical 显式锁定同版本。帖子目前使用普通 textarea，本期助手仅接入文章 MDXEditor，复杂节点和帖子编辑助手为后续范围。


## 兼容历史：发布后摘要（2026-10-02）

以下记录旧客户端行为，当前界面使用上文的发布前确认流程。

标题从正文首个顶层 Markdown 标题提取（代码块/引用中的标题不计）；新建日期地址由 API 自动分配，已发布地址不变。没有独立标题、封面输入；既有封面数据保留。摘要区为只读，展示最新发布任务状态。发布请求传当前选中的助手；任务由后台持久化，离开页面仍可完成，模型故障不阻断发布，再次发布可重试。自动摘要仅更新匹配的快照，不发布用户继续编辑的工作稿。客户端根据 summaryStatus 轮询文章，不创建摘要任务；后台摘要唯一改变 version 时，保存可安全重试一次，其他内容冲突要求重新打开。

分类与标签位于 WRITING SPACE/正文标题下方、编辑器工具栏上方。输入时过滤全部已有词，鼠标或方向键选中；按回车复用已有名称或创建新名称，支持中文输入法组合。分类单选，标签多选且可移除；未确认的新词在点击保存/发布前创建并纳入这次保存。新词创建冲突后刷新并复用目录；不会重复加入同一个标签。

## 更新：发布前确认
