# 所见即所得编辑器 v0.1

状态：用户已确认编辑体验；MDXEditor、Markdown 保存和粘贴 PNG 图片已完成浏览器联调。本文件同时记录尚需扩充的格式与异常场景验收要求。

## 编辑体验

正文在同一个区域里直接编辑排版结果。标题、加粗、列表、引用、代码块、表格和图片立即显示，无需切换到预览页，也不要求左右分屏。提供常用格式工具栏及 Markdown 输入快捷方式；中文输入、选区、光标和撤销/重做必须正常工作。

粘贴图片后，在当前位置显示上传占位和进度；上传成功后该位置直接显示图片。站长不用手动拼写图片 Markdown。可编辑图片说明，上传失败可重试或移除。光标移动、撤销、删除占位、切换文章后，异步上传结果都不能插入错误位置或复活已删除图片。

保存工作稿与发布仍是不同操作。排版结果实时可见不意味着已经保存，更不意味着已对访客公开。

## 正文与接口

集成成熟编辑器组件，不从零实现编辑引擎。当前采用 MDXEditor，具体安装版本以 package.json/锁文件为准；更换组件前仍须验证 Markdown 解析/序列化、中文输入、图片节点和粘贴上传扩展。下文格式范围与异常保护含长期验收要求，不等于全部样例已经通过。

数据流：

```text
数据库 bodyMarkdown → 解析为编辑器文档 → 同一区域可视编辑
                                  ↓ 保存时序列化
                           Markdown → 管理 API → 工作稿
                                                   ↓ 明确发布
                                               发布快照
                                                   ↓
                                           公开站安全渲染
```

数据库和文章 API 继续以 `bodyMarkdown` 为正文格式。编辑器内部结构只用于交互，不作为第二份权威正文；不改成存储编辑器 HTML 或专有 JSON。文字输入在本地编辑器内立即更新，不逐字请求服务端重新渲染，也不在每次输入时重建整个编辑器导致光标跳动。

第一版格式范围建议采用 CommonMark 常用结构＋GFM 表格、任务列表与删除线：段落、标题、粗体/斜体、链接、图片、引用、有序/无序及嵌套列表、行内代码、带语言的围栏代码块、分隔线和换行。其解析、序列化与公开渲染规则需要用样例共同验证。公式支持见下文；脚注和提示块按后续内容需要扩展。

往返保存要求保留内容语义、代码空白与语言标记、链接、图片地址、图片说明和列表结构；允许等价 Markdown 写法归一化，不要求逐字相同。仅打开文章不能触发保存或把格式归一化当成用户修改。遇到暂不支持的结构，不得静默删除再保存：保留原始正文、提示具体问题，必要时进入只读保护，待提供可保留该结构的编辑方式后再保存。

## 数学公式

已保存或导入的 `$...$` 行内公式、独立行 `$$` 包围的块公式渲染为 KaTeX，代码中的美元符号仍是字面量。工具栏“∑ 公式”在光标处插入，选择行内/独立显示后输入 TeX 源码并实时预览；点击现有公式可修改源码或删除，支持取消及撤销。直接在普通文本里逐字键入美元分隔符不触发数学快捷转换，请使用公式工具。

正文仍保存 Markdown/TeX 源码，不保存渲染 HTML；错误公式保留可读源码，外围粗体、斜体和删除线往返不丢失。公式装饰节点的复制 HTML 输出可读 TeX，编辑器内部剪贴板保留节点。公式所在段落中的普通文字仍支持助手选区修改，光标写入只能位于公式外。

编辑器、助手回复及建议预览复用 `shared/ui/MathFormula` 的安全选项；助手使用 remark-math/rehype-katex，编辑器通过 `mathPlugin` 的公开 MDXEditor 扩展点导入导出。禁止可信宏，限制展开次数和尺寸；KaTeX 固定版本并使用 npm override 对齐渲染器及插件，避免重复版本与样式不一致。长公式在自身区域横向滚动。公开站实现与样式由 lantern 独立维护。

`tests/browser/math-editor.spec.ts` 覆盖公式往返、不标脏、插入/修改/取消/删除/撤销、危险宏、窄屏及格式/助手选区；回复公式见 `writing-messages.spec.ts`。

## 私密图片

图片节点保留后端返回的稳定公开地址作为正文数据，编辑时的显示层通过站长认证后的 `previewUrl` 取图。序列化后仍为 `![说明](稳定地址)`；私密预览地址、临时 blob URL、上传进度和会话信息不得写入 `bodyMarkdown`。更不能从显示层 DOM 反向采集地址并误存为正文。

使用编辑器事务/节点映射保持上传占位与插入位置关联，不仅保存粘贴时的字符串下标。上传成功只更新仍存在且属于当前文档的占位节点；保存前确保所有需保留图片都已有持久地址。

对应接口和权限以 [wellspring 图片契约](https://github.com/raychi-space/wellspring/blob/main/docs/api/assets-v0.1.md) 为准；首次发布前及已发布文章的新工作稿图片仍不可被访客读取。

## 验收重点

- 输入和工具栏操作立即在原编辑区域显示排版，无需手动保存或点预览。
- 中文输入法组合输入不被打断，光标不跳动，撤销/重做顺序合理。
- 使用一份包含上述格式的文章完成“加载→编辑→保存→重新打开→公开渲染”，检查结构、文字、代码和图片一致。
- 私密图片在编辑区可见，序列化保存的始终是稳定地址；匿名直链仍返回 404。
- 上传过程中移动光标、连续输入、多图完成顺序不同、删除或撤销占位、切换文章，均不串图或覆盖新内容。
- 不支持的格式触发保护，保存失败保留本地编辑内容，不覆盖服务端版本。
- 已发布文章的所见即所得修改只写入工作稿，再次发布才更新访客看到的内容。
