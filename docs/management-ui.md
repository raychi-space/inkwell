# 管理台页面与侧栏

[inkwell#12](https://github.com/raychi-space/inkwell/issues/12) · [PR #11](https://github.com/raychi-space/inkwell/pull/11)

## 网站管理

网站管理与内容管理、草稿箱共用页面背景、标题和卡片样式。桌面端侧栏和页头固定，设置表单在内容区内滚动；手机端表单改为单列。

保留站名、头像、个人介绍、关注方向、项目、联系方式、社交账户、其他链接与页脚等实际展示字段。导航、首屏内容顺序与显示、页面下方顺序与显示不再提供编辑区域。读取后保存仍保留这些已有字段的值，不重置公开站的现有配置；后端契约不变。

头像和站名读取网站设置。保存后侧栏立即更新；没有头像或图片加载失败时显示本地图形。账户名来自当前登录会话。

## 侧栏与账户

展开时显示 Logo、站名、四个导航入口和底部头像账户入口。顶部收起按钮将侧栏变为图标栏，只显示 Logo、导航图标和头像；悬停提示与无障碍名称仍保留。点击收起状态的 Logo 可展开。

收起偏好保存在当前浏览器本地，不写入服务端。手机首次打开默认收起；展开时覆盖内容并显示遮罩，可通过顶部按钮或遮罩收起。浏览器不允许本地存储时，偏好只保持当前页面。

点击头像打开账户菜单，可退出登录；按 Escape 关闭菜单并返回头像焦点，点击菜单外也可关闭。退出继续使用原有会话接口。

## 助手与模型服务商

助手管理采用上下布局：上方是助手，下方是模型服务商。各区通过左侧列表选择配置，右侧编辑详情；窄屏列表放在详情上方。名称、状态与模型信息来自现有接口，不使用服务商预设代替已保存数据。

“新增助手”和“新增服务商”分别创建新配置；模型按行添加、修改或移除。密钥保留、连接测试和运行预算见[写作助手说明](writing-assistant-v1.md)。切换同一区域的配置且有未保存输入时，会显示符合主题的确认框，可返回编辑或放弃修改并切换。

参考 quick-assistant-app 的列表与详情编辑方式、模型行和密钥保留交互。本期仍使用已有 OpenAI-compatible 契约，不增加协议适配或复制其他应用的服务商预设。
