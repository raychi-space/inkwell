# 管理台页面与侧栏

[inkwell#12](https://github.com/raychi-space/inkwell/issues/12) · [PR #11](https://github.com/raychi-space/inkwell/pull/11)

## 网站管理

网站管理与内容管理、草稿箱共用页面背景、标题和卡片样式。桌面端侧栏和页头固定，设置表单在内容区内滚动；手机端表单改为单列。

进入网站管理时先显示当前登录会话中已读取的设置，再后台读取最新值。刷新期间的输入不会被迟到响应覆盖；保存后更新会话内快照，退出登录时清除。首次没有快照时使用静态表单占位，不先显示一个会突然展开的小卡片。验证见[网站设置切换记录](verification/settings-transition-2026-10-02.md)。

保留站名、头像、个人介绍、关注方向、项目、联系方式、社交账户、其他链接与页脚等实际展示字段。导航、首屏内容顺序与显示、页面下方顺序与显示不再提供编辑区域。读取后保存仍保留这些已有字段的值，不重置公开站的现有配置；后端契约不变。

头像和站名读取网站设置。保存后侧栏立即更新；没有头像或图片加载失败时显示本地图形。账户名来自当前登录会话。

## 侧栏与账户

展开时显示 Logo、站名、四个导航入口和底部头像账户入口。顶部收起按钮将侧栏变为图标栏，只显示 Logo、导航图标和头像；悬停提示与无障碍名称仍保留。点击收起状态的 Logo 可展开。

展开与收起使用 240 毫秒的宽度过渡，文字淡入淡出；Logo、导航图标和头像的大小及位置不随状态变化。系统要求减少动画时关闭侧栏过渡。

收起偏好保存在当前浏览器本地，不写入服务端。手机首次打开默认收起；展开时覆盖内容并显示遮罩，可通过顶部按钮或遮罩收起。浏览器不允许本地存储时，偏好只保持当前页面。

点击头像打开账户菜单，可修改密码或退出登录；按 Escape 关闭菜单并返回头像焦点，点击菜单外也可关闭。退出继续使用原有会话接口。

## 助手与模型服务商

助手管理是独立页面，只管理助手。模型服务商位于网站管理的最下方，保存按钮与网站展示设置分开。两者通过左侧列表选择配置，右侧编辑详情；窄屏列表放在详情上方。名称、状态与模型信息来自现有接口，不使用服务商预设代替已保存数据。

“新增助手”和“新增服务商”分别创建新配置；模型按行添加、修改或移除。密钥保留、连接测试和运行预算见[写作助手说明](writing-assistant-v1.md)。切换同一区域的配置且有未保存输入时，会显示符合主题的确认框，可返回编辑或放弃修改并切换。

参考 quick-assistant-app 的列表与详情编辑方式、模型行和密钥保留交互。本期仍使用已有 OpenAI-compatible 契约，不增加协议适配或复制其他应用的服务商预设。

### 助手图标与服务商 Logo

助手详情可选择 Lucide 或 Emoji 图标，保存配置后刷新仍保留；助手列表和写作页展示所选图标。图标以预设标识符保存，旧助手缺省使用默认机器人图标，不接受任意图片 URL。

服务商列表、详情及助手的服务商下拉框继续展示服务商品牌 Logo。支持 OpenAI、DeepSeek、Anthropic、Gemini、Qwen、智谱、Moonshot、SiliconFlow、OpenRouter、Groq、Mistral 和 Ollama。品牌图标沿用 quick-assistant-app 的本地 Lobe Icons SVG，许可证见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)，加载时无需请求外部图片服务。

品牌优先依据 API 地址的主机名识别；自建代理或本机连接可通过服务商名称识别。名称包含多个品牌、未知品牌或缺少服务商时显示通用连接图标。OpenAI-compatible 协议和模型 ID 不用于判断品牌，例如 OpenRouter 连接中的 DeepSeek 模型仍显示 OpenRouter。品牌识别仅用于显示，不改变调用地址、密钥或已保存配置。

### 页面密度

内容管理、草稿箱、网站管理、助手管理及编辑器统一使用 30px 页标题，手机端为 26px；区块标题为 17px。缩小页头、卡片和配置表单间距，设置输入使用 12px 字号；手机输入和下拉框保留至少 40px 高度。正文编辑区使用 16px 字号，列表和设置区保持各自的滚动方式。

早期品牌图标、键盘选择与桌面/手机验证见[验证记录](verification/provider-logos-density-2026-10-02.md)。后续助手图标库和固定写作工作区见[2026-10-04 发布验收](https://github.com/raychi-space/raychi/issues/39#issuecomment-5971077966)；历史页面尺寸记录不替代后续写作页布局。

## 修改密码

账户菜单 → 修改密码：填写当前密码、新密码和确认新密码。新密码至少 12 个字符，UTF-8 最多 72 字节，不能与旧密码相同；中文占多个字节，页面会校验实际字节数。错误保留表单和会话，提交中禁用重复操作；成功返回登录页并提示使用新密码，其他设备会话也失效。密码只存在当前表单状态，不写入浏览器存储。离开正在编辑的内容仍沿用未保存确认。
