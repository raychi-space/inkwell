# 管理台页面与侧栏

[inkwell#12](https://github.com/raychi-space/inkwell/issues/12) · [PR #11](https://github.com/raychi-space/inkwell/pull/11)

## 概览

登录后默认打开“概览”，侧栏也可随时返回；离开未保存的编辑仍遵守现有保护。顶部显示北京时间今日浏览量和匿名访客、全站已发布内容和草稿数量。已发布与草稿按内容状态统计，包含文章和帖子；已发布内容存在未发布修改时，最近内容单独标记，不计入草稿数。最近内容按更新时间倒序最多展示五条，可打开编辑；写文章、写帖子沿用现有新建流程。

近 7 天访问折线复用统计页的鼠标、触摸和键盘交互；拾阅区展示 API/Worker 心跳、今日采集、待处理、失败来源数和检查时间。快捷链接进入相应管理页。进入和刷新仅进行只读查询，不触发采集或模型调用；各区独立显示未配置或读取失败，失败不表示零。桌面沿用固定页头及内容区滚动，手机布局可自然滚动。

数据来自内容、访问统计和拾阅现有管理 API，不增加前端密钥或配置。统计卡与折线共用既有统计口径；内容列表 total 为全站数量，不使用内容管理中的本页统计。`tests/browser/overview.spec.ts` 为接口替身回归，覆盖默认入口、口径、只读刷新、局部失败、图表和桌面/手机布局；真实服务联调需另行执行。

## 写作主题

默认使用柔和暖灰浅色，减少纯白背景；头像账户菜单可选择“暖灰”“深色”或“跟随系统”。主题立即应用到后台页面、表单、编辑器工具栏、源码区、对话和修改差异；不改变公开站主题。主题偏好是非敏感的浏览器本地设置，刷新后保留；禁止本地存储时本页仍可切换。“跟随系统”会响应系统配色变化，深色通过 MDXEditor 原生 `dark-theme` 及共享颜色变量适配。

颜色角色统一维护于 `src/style.css` 的 `--studio-*` 变量，不再为组件分别复制浅色/深色配色。主题初始化在 React 挂载前执行，行为在 `shared/lib/theme.ts`，账户菜单使用 `shared/ui/ThemePicker.tsx`。新增内容应复用正文、面板、边框、强调色、错误以及增删差异颜色。

## 网站管理

网站管理与内容管理、草稿箱共用页面背景、标题和卡片样式。桌面端侧栏和页头固定，设置表单在内容区内滚动；手机端表单改为单列；自然展开的管理区允许手势继续带动整页，内容列表在边缘同样允许滚动传递。

进入网站管理时先显示当前登录会话中已读取的设置，再后台读取最新值。刷新期间的输入不会被迟到响应覆盖；保存后更新会话内快照，退出登录时清除。首次没有快照时使用静态表单占位，不先显示一个会突然展开的小卡片。验证见[网站设置切换记录](verification/settings-transition-2026-10-02.md)。

保留站名、头像、个人介绍、关注方向、项目、联系方式、社交账户、其他链接与页脚等实际展示字段。导航、首屏内容顺序与显示、页面下方顺序与显示不再提供编辑区域。读取后保存仍保留这些已有字段的值，不重置公开站的现有配置；后端契约不变。

头像和站名读取网站设置。保存后侧栏立即更新；没有头像或图片加载失败时显示本地图形。账户名来自当前登录会话。

## 侧栏与账户

展开时显示 Logo、站名、四个导航入口和底部头像账户入口。顶部收起按钮将侧栏变为图标栏，只显示 Logo、导航图标和头像；悬停提示与无障碍名称仍保留。点击收起状态的 Logo 可展开。

展开与收起使用 240 毫秒的宽度过渡，文字淡入淡出；Logo、导航图标和头像的大小及位置不随状态变化。系统要求减少动画时关闭侧栏过渡。

收起偏好保存在当前浏览器本地，不写入服务端。手机首次打开默认收起；展开时覆盖内容并显示遮罩，可通过顶部按钮或遮罩收起。浏览器不允许本地存储时，偏好只保持当前页面。

点击头像打开账户菜单，可修改密码或退出登录；按 Escape 关闭菜单并返回头像焦点，点击菜单外也可关闭。退出继续使用原有会话接口。

## 助手与模型服务商

助手管理是独立页面，只管理助手。模型服务商位于网站管理的最下方，保存按钮与网站展示设置分开。两者通过左侧列表选择配置，右侧编辑详情；窄屏列表放在详情上方。名称、状态与模型信息来自现有接口，不使用服务商预设代替已保存数据。

“新增助手”和“新增服务商”分别创建新配置；模型按行添加、修改或移除。密钥保留、连接测试和运行预算见[写作助手说明](writing-assistant-v1.md)。切换同一区域的配置且有未保存输入时，会显示符合主题的确认框，可返回编辑或放弃修改并切换。

参考 quick-assistant-app 的列表与详情编辑方式、模型行和密钥保留交互。本期仍使用已有 OpenAI-compatible 契约，不增加协议适配或复制其他应用的服务商预设。

### 助手图标与服务商 Logo

助手详情可选择 Lucide 或 Emoji 图标，保存配置后刷新仍保留；助手列表和写作页展示所选图标。图标以预设标识符保存，旧助手缺省使用默认机器人图标，不接受任意图片 URL。

服务商列表、详情及助手的服务商下拉框继续展示服务商品牌 Logo。支持 OpenAI、DeepSeek、Anthropic、Gemini、Qwen、智谱、Moonshot、SiliconFlow、OpenRouter、Groq、Mistral 和 Ollama。品牌图标沿用 quick-assistant-app 的本地 Lobe Icons SVG，许可证见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)，加载时无需请求外部图片服务。

品牌优先依据 API 地址的主机名识别；自建代理或本机连接可通过服务商名称识别。名称包含多个品牌、未知品牌或缺少服务商时显示通用连接图标。OpenAI-compatible 协议和模型 ID 不用于判断品牌，例如 OpenRouter 连接中的 DeepSeek 模型仍显示 OpenRouter。品牌识别仅用于显示，不改变调用地址、密钥或已保存配置。

### 页面密度

内容管理、草稿箱、网站管理、助手管理及统计页沿用公共 PageHeader 的 26px 标题；区块标题为 17px。编辑器保留自身工作区排版。缩小页头、卡片和配置表单间距，设置输入使用 12px 字号；手机输入和下拉框保留至少 40px 高度。正文编辑区使用 16px 字号，列表和设置区保持各自的滚动方式。

访问统计页采用紧凑卡片：区块间距为 10–12px，缩小指标卡、图表和表格的内边距与高度。桌面页头固定，内容区复用 `management-scroll` 独立滚动；手机自然展开为整页滑动，筛选与分页控件保持至少 40px 高度。后台只展示全站访问量，以及明细中的访问时间、IP、归属地和来源；不提供页面路径筛选或访问页面列。底层继续采集路径，按页面统计能力留供后续公开页接入。

每日数值直接显示在折线提示框中，不另设折叠数值表：鼠标悬停、手机点按均可查看日期和 PV，键盘聚焦图表后用左右方向键切换日期，Home/End 跳至首尾，Escape 收起。来源排行复用已采集的外部来源域名，显示 PV 及其在当前筛选区间浏览量中的占比；浏览器未提供来源和直接访问合并为“直接访问或未知”。点击域名或此合并项联动筛选图表和明细，保留已应用的日期、IP、地区条件并返回第一页；再次点击选中来源或“清除来源筛选”只清除来源条件。未提交的表单编辑不会混入这次排行查询，四张总量卡保持全站口径。来源行较多时卡片内可滚动，长域名换行；读取失败保留上一份成功数据和选中状态，显式重试后才更新。

早期品牌图标、键盘选择与桌面/手机验证见[验证记录](verification/provider-logos-density-2026-10-02.md)。后续助手图标库和固定写作工作区见[2026-10-04 发布验收](https://github.com/raychi-space/raychi/issues/39#issuecomment-5971077966)；历史页面尺寸记录不替代后续写作页布局。

## 修改密码

账户菜单 → 修改密码：填写当前密码、新密码和确认新密码。新密码至少 12 个字符，UTF-8 最多 72 字节，不能与旧密码相同；中文占多个字节，页面会校验实际字节数。错误保留表单和会话，提交中禁用重复操作；成功返回登录页并提示使用新密码，其他设备会话也失效。密码只存在当前表单状态，不写入浏览器存储。离开正在编辑的内容仍沿用未保存确认。

## 滚动回归

满页回收站列表与短屏改密表单各自可滚动，底部操作完整可达；不依赖程序强制滚动隐藏区域。`tests/browser/admin-layout.spec.ts` 验证长列表和短屏按钮，统计用例验证固定页头、320px 触摸滚动及表格横向可达性。真实跨服务验收另外在 390px/320px 逐页检查后台导航、基础样式与滑动。

## 拾阅管理

AIHOT 模式下使用三个页签，沿用固定页头与紧凑卡片。运行看板显示 API/Worker 心跳、来源健康、今日采集、待处理及已发布数，近7天北京时间采集/处理趋势、模型用量/限额和可筛选分页任务；异常只展示分类。采集来源支持 RSS 搜索、启用/健康筛选、分页、新增并启用、编辑版本、暂停/恢复、检查RSS和立即采集。检查只预览数量、不保存材料；采集明确入队，不在刷新时触发。模型与限额展示已配置模型与各处理环节、每分钟/小时/滚动24小时限额、成功率/耗时/Token；0暂停请求。配置同步未知时不能切换模型。

顶部手动刷新只查询接入状态与当前页签数据；不会自动轮询、重新处理历史材料或绕过预算。未保存表单在切换页签、侧栏、刷新及离开页面时受保护；保存期间禁止打断表单的筛选、导航和重复提交。保存某项配置保留其他模型/限额草稿，查询的迟到响应不会覆盖新的编辑。

表格在卡片内横向滚动，页签可换行；桌面工作区独立滚动，窄屏沿用现有页面滚动与侧栏收起规则。`tests/browser/reading-management.spec.ts` 为接口替身回归，覆盖只读刷新、分页、已配置模型、未保存/保存中保护及1280/390/320宽度。真实服务/SQL证据归跨仓主任务 #96，替身不代表上游服务已部署。

旧后端404或 legacy 模式仍保留原拾阅表单；未配置新管理凭据时显示未配置状态，公开拾阅仍可使用。凭据不在本仓配置，接口与更新口径见 [wellspring 拾阅管理 v1](https://github.com/raychi-space/wellspring/blob/main/docs/api/reading-management-v1.md)。
